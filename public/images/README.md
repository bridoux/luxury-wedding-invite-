# Images

Drop your real photos here, then reference them in `lib/config.ts`.

Expected (optional) files — the app shows elegant gradient placeholders
automatically if any are missing:

- `story-1.jpg` … `story-4.jpg` — Our Story timeline photos
- `gallery-1.jpg` … `gallery-6.jpg` — Gallery grid photos

Recommended: optimized JPG/WebP, ~1200px wide, under ~300KB each.
