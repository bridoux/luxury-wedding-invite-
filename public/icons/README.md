# App Icons

`icon.svg` is a ready-to-use scalable monogram icon (works for most needs).

For best PWA install results on Android/iOS, also add raster icons:

- `icon-192.png` (192×192)
- `icon-512.png` (512×512)

Quickest way: open `icon.svg` in any browser, screenshot/export at the sizes
above, or use a tool like https://realfavicongenerator.net. These are already
referenced in `public/manifest.json`.
